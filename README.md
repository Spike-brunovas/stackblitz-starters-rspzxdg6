# Calculadora Web

Projeto simples de uma calculadora feita com HTML, CSS e JavaScript.

## Estrutura

- `index.html` — página principal da calculadora.
- `script.js` — lógica dos cálculos.
- `styles.css` — estilos da interface.
- `pages/` — páginas auxiliares.
- `package.json` — configuração do projeto e comando de desenvolvimento.
- `.gitignore` — arquivos ignorados pelo Git.

## Executar

Instale as dependências e execute:

```bash
npm install
npm start
```

A página principal continua em `index.html`, preservando a compatibilidade com o projeto atual.
